SAPyL

Raspador do Sistema de Apoio Legislativo

Acompanhe, num só lugar, o que está tramitando em dezenas de câmaras e assembleias brasileiras que usam o SAPL.

Ver no GitHub Como instalar

O que é

Muitas Câmaras Municipais e Assembleias Legislativas publicam seus projetos de lei, requerimentos e outras matérias no SAPL (Sistema de Apoio ao Processo Legislativo, do Interlegis). Cada casa tem o seu site, e não há uma busca que junte todas. O SAPyL faz essa busca por você e entrega o resultado numa planilha.

Dados públicos

O que as casas já publicam, organizado: título, ementa, data, tipo, situação e o link do texto original de cada matéria.

Software livre

Código aberto sob a licença AGPL-3.0. Você pode usar, estudar, modificar e redistribuir, desde que as versões continuem livres.

Casas legislativas

Uma tabela com centenas de câmaras e assembleias que usam o SAPL. Você escolhe todas, as de Sul e Sudeste ou só algumas para testar.

Para quem

  • Pesquisadoras e pesquisadores
  • Jornalistas
  • Organizações da sociedade civil
  • Quem quer saber o que está sendo proposto sobre um tema em muitas casas ao mesmo tempo

Como funciona

  1. Busca. Pesquisa cada palavra-chave no sistema de busca de cada casa.
  2. Links. Junta os links das matérias encontradas, sem repetir: uma matéria achada por várias palavras aparece uma vez, com todas as palavras.
  3. Matérias. Lê os dados de cada matéria pela API do SAPL (ou pela página, nas casas sem API).
  4. Planilha. Grava tudo num CSV que abre em qualquer planilha.
  5. Textos. Se você quiser, baixa os textos originais (PDFs).

Nenhuma matéria vazia em silêncio. Toda linha tem status (ok ou erro) e, quando falha, o motivo.

Respeito aos servidores. No máximo 35 requisições por minuto em cada site.

Retomada. Se parar no meio, rode de novo e escolha “retomar”: nada do que já foi feito é refeito.

Instalar

Você precisa do Python 3.10 ou mais novo e do git.

Linux e macOS

git clone https://github.com/leoaucar/sapyl.git
cd sapyl
python3 -m venv .venv
source .venv/bin/activate
pip install .

Windows (PowerShell)

git clone https://github.com/leoaucar/sapyl.git
cd sapyl
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install .

Pronto: o comando sapyl fica disponível sempre que o ambiente (.venv) estiver ativado. Confira com sapyl --version.

Usar

  1. Escolha as palavras-chave

    Crie arquivos_csv/palavras_chave.csv com uma coluna Palavras. Cada linha é uma busca. Há um exemplo pronto em arquivos_csv/exemplo_palavras_chave.csv.

    Palavras
plano diretor
"orçamento, emenda impositiva"
saneamento básico
saneamento basico
    • Termos com espaço viram uma expressão exata.
    • Termos separados por vírgula na mesma linha são buscados juntos.
    • Com e sem acento? Coloque as duas grafias, em linhas separadas.

    Busca no SAPL:

  2. Rode o programa

    sapyl

    Ele faz algumas perguntas no terminal, a primeira é o que fazer:

    • 1 Novo projeto ou retomar um projeto
    • 2 Atualizar um projeto (raspa de novo as matérias do resultado)
    • 3 Autoria e tramitação (acrescenta autores e o último trâmite)

    Num projeto novo, você dá um nome e escolhe se quer restringir a Sul e Sudeste, limitar o número de casas para testar e baixar os PDFs.

  3. Abra o resultado

    Tudo fica na pasta <nome>_proj/. A planilha é <nome>_resultado_final.csv; os PDFs ficam em downloads/ e o registro de cada execução em logs/.

Quanto tempo leva?

Cada site do SAPL aceita no máximo 35 requisições por minuto, e o SAPyL respeita esse limite. Uma casa com 1 000 matérias leva cerca de 30 minutos. Se a execução parar, rode de novo, digite o mesmo nome e escolha retomar.

O SAPyL trabalha em até 8 casas ao mesmo tempo. Como quase todas ficam no mesmo servidor do Interlegis, elas dividem um limite de 120 requisições por minuto por servidor: uma busca em todas as casas fica cerca de três vezes mais rápida do que uma casa por vez, mas ainda leva horas. Se quase todas as matérias são de uma casa só, a busca leva o tempo dessa casa.
