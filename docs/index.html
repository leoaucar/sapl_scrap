Raspador do Sistema de Apoio Legislativo

Ver no GitHub Como instalar

O que é

Mais de mil casas legislativas (câmaras municipais e algumas assembleias estaduais) estão na lista das que publicam seus projetos de lei, requerimentos e outras matérias no SAPL (Sistema de Apoio ao Processo Legislativo), desenvolvido pelo programa Interlegis do Senado Federal. Cada casa tem o seu site, e não há uma busca que junte todas. O SAPyL faz essa busca unificada e entrega o resultado numa planilha.

Dá para pesquisar a produção legislativa sobre qualquer assunto: educação, saúde, segurança pública, assistência social… Os resultados podem e devem servir de base para pesquisas acadêmicas e para o trabalho de movimentos sociais em prol da mudança social. O SAPyL é software livre e de código aberto: use e ajude a melhorar.

Origem

O SAPyL foi criado para apoiar o mapeamento da atuação do ultraconservadorismo e da extrema direita nos legislativos em pautas educacionais. Essa pesquisa foi uma das frentes do projeto Gênero e Políticas Educacionais, realizado entre 2023 e 2025 numa parceria entre Ação Educativa, Faculdade de Educação da Universidade de São Paulo (FE-USP), Fundação Carlos Chagas (FCC), Geledés – Instituto da Mulher Negra e Coletivo Professor@s contra o Escola sem Partido, com apoio do Fundo Malala.

Como funciona

  1. Busca. Pesquisa cada palavra-chave no sistema de busca de cada casa.
  2. Links. Junta os links das matérias encontradas, sem repetir: uma matéria achada por várias palavras aparece uma vez, com todas as palavras.
  3. Matérias. Lê os dados de cada matéria pela API do SAPL (ou pela página, nas casas sem API).
  4. Planilha. Grava tudo num CSV que abre em qualquer planilha.
  5. Textos. Se você quiser, baixa os textos originais (PDFs).

Nenhuma matéria vazia em silêncio. Toda linha tem status (ok ou erro) e, quando falha, o motivo.

Respeito aos servidores. No máximo 35 requisições por minuto em cada site.

Retomada. Se parar no meio, rode de novo e escolha “Retomar um projeto”: nada do que já foi feito é refeito.

Instalar

O SAPyL roda pelo terminal (a tela de comandos do computador). Não é preciso saber programar: copie os comandos, um de cada vez, e aperte Enter. A instalação é feita uma vez só.

  1. Instale o Python 3.10 ou mais novo (no Windows, marque “Add python.exe to PATH” na primeira tela) e o git. No Ubuntu e no Debian, instale também python3-venv.
  2. Abra o terminal: no Windows, o PowerShell (menu Iniciar); no macOS, o app Terminal; no Linux, o Terminal.
  3. Baixe o SAPyL do GitHub. Sem o git: botão verde <> Code → Download ZIP, descompacte (no Windows, botão direito → Extrair tudo) e entre na pasta sapyl-main, pulando a linha do git clone. Com o git, o git clone abaixo cria a pasta sapyl.
  4. Copie os comandos do seu sistema:

Linux e macOS

git clone https://github.com/leoaucar/sapyl.git
cd sapyl
python3 -m venv .venv
source .venv/bin/activate
pip install .

Baixa o código, entra na pasta, cria o ambiente do programa (.venv), ativa esse ambiente e instala o SAPyL dentro dele.

Windows (PowerShell)

git clone https://github.com/leoaucar/sapyl.git
cd sapyl
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install .

Se aparecer “a execução de scripts foi desabilitada neste sistema”, rode uma vez Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, responda S e ative de novo.

Pronto. O ambiente (.venv) é a pasta onde ficam o programa e as bibliotecas dele. Ele foi criado uma vez só, mas precisa ser ativado toda vez que você abrir um terminal novo (veja abaixo). Sem o git, baixe o ZIP no GitHub (Code → Download ZIP), descompacte e pule o git clone. Para atualizar: git pull e pip install . de novo (ou um ZIP novo, copiando as suas pastas <nome>_proj e arquivos_csv).

Usar

  1. Escolha as palavras-chave

    Crie arquivos_csv/palavras_chave.csv com uma coluna Palavras. Cada linha é uma busca. Há um exemplo pronto em arquivos_csv/exemplo_palavras_chave.csv.

    Palavras
plano diretor
"orçamento, emenda impositiva"
saneamento básico
saneamento basico
    • Termos com espaço viram uma expressão exata.
    • Termos separados por vírgula na mesma linha são buscados juntos.
    • Com e sem acento? Coloque as duas grafias, em linhas separadas.

    Busca no SAPL:

  2. Rode o programa

    Toda vez que for usar: abra o terminal, entre na pasta do SAPyL e ative o ambiente.

    cd sapyl
source .venv/bin/activate      # Linux e macOS
.venv\Scripts\Activate.ps1     # Windows (PowerShell)

    Com o ambiente ativado, a linha do terminal começa com (.venv). Então:

    sapyl

    Se aparecer “command not found” ou “o termo 'sapyl' não é reconhecido”, o ambiente não está ativado ou você está fora da pasta do SAPyL.

    Ele mostra um menu no terminal; escolha com as setas e Enter:

    • Novo projeto
    • Retomar um projeto (da lista, com a situação de cada um)
    • Atualizar um projeto (raspa de novo as matérias do resultado)
    • Autoria e tramitação (acrescenta autores e o último trâmite)
    • Ajuda e Sair

    Num projeto novo, ele mostra as suas palavras-chave, pede um nome, os estados (marcados numa lista) e se é para baixar os PDFs. Toda pergunta tem ← Voltar, que volta uma pergunta sem perder as respostas. Antes de começar, um resumo do que vai ser feito: começar, voltar ou cancelar. Durante a execução, um painel mostra as casas concluídas, as buscas, as matérias e o tempo restante.

  3. Abra o resultado

    Tudo fica na pasta <nome>_proj/. A planilha é <nome>_resultado_final.csv; os PDFs ficam em downloads/ e o registro de cada execução em logs/.

Quanto tempo leva?

Cada site do SAPL aceita no máximo 35 requisições por minuto, e o SAPyL respeita esse limite. Uma casa com 1 000 matérias leva cerca de 30 minutos. Se a execução parar, rode de novo e escolha Retomar um projeto.

O SAPyL trabalha em até 8 casas ao mesmo tempo. Como quase todas ficam no mesmo servidor do Interlegis, elas dividem um limite de 120 requisições por minuto por servidor: uma busca em todas as casas fica cerca de três vezes mais rápida do que uma casa por vez, mas ainda leva horas. Se quase todas as matérias são de uma casa só, a busca leva o tempo dessa casa.
